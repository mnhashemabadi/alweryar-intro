# آلوریار

آلوریار را برای همکاران آلور ساختم. روی سایت دو کار هست: همکاری در بررسی آگهی، و همکاری در فروش. تا همکار معتمد شود، انتشار با تأیید آلور است.

سایت: [alweryar.ir](https://alweryar.ir)

بازار: [alwer.ir](https://alwer.ir)

آلوریار یک وب‌سایت است و برنامهٔ همراه دارد.

## English

I built Alweryar for Alwer's collaborators. The site names two kinds of work: collaboration on listing review, and collaboration on sales. Until a collaborator is trusted, publishing goes through Alwer's approval.

Site: [alweryar.ir](https://alweryar.ir)

Market: [alwer.ir](https://alwer.ir)

Alweryar is a website and a companion app.
